--------------------------------------------------------------------------------
一、模型基本信息
--------------------------------------------------------------------------------
- 算法: PatchCore (One-Class 无监督异常检测，只用工艺术良品训练)
- 主干: ResNet18 (ImageNet 预训练), 特征层 layer2+layer3 (384 维)
- coreset 记忆库: 61440 个特征
- 训练数据: 域适配模拟弯曲圆弧条纹 (train 300 良品) + val 良品 100 + test 1300
- 评估 (test 1300: 良品100 + 缺陷1200):
    image_AUROC = 0.8109
    image_F1    = 0.9602
- 域适配改进: 模拟数据已调成高对比细密条纹+扫描线+亮度渐变+模糊,
  使其更接近 11.avi/13.avi 真实成像; 相对旧模型 AUROC 0.7950 -> 0.8109

--------------------------------------------------------------------------------
二、ONNX 接口（与 C++ DeepWaferDetector.cpp 约定一致）
--------------------------------------------------------------------------------
输入:
   节点名  : input
   形状    : [batch, 3, 256, 256]  (batch=1)
   类型    : float32
   数值范围: [0,1]，即像素 /255（不做 ImageNet mean/std 归一化）
   通道顺序: NCHW（C++ 已用 blobFromImage 转好）
   输入内容: 灰度帧 → 复制为 3 通道 或 BGR 原样 → resize 到 256×256

输出（C++ 只取下面两个节点名）:
   节点名  : pred_score    形状 [1]           float32  图像级异常分数(已归一化 0~1)
   节点名  : anomaly_map   形状 [1,1,256,256] float32  像素级热力图(已归一化)

验证结果（Python ONNX Runtime, CPU）:
   ✅ 模型可加载（输入/输出节点名匹配）
   ✅ 6 张良品+缺陷样本 score/anomaly_map 正常
   ✅ 无 NaN / Inf
   ✅ ONNX 与 PyTorch 推理一致（score 差值 < 1e-5）
   score 示例: 良品 0.59/0.66, 缺陷 spacing_jump 0.93 / direction_change 1.0
               / broken_arc 0.71 / brightness_spot 0.56

--------------------------------------------------------------------------------
三、推荐判定阈值（重要！旧阈值 0.54/0.72 是基于旧模型的，需更新）
--------------------------------------------------------------------------------
本模型分数已归一化。test 集分数统计:
   良品 100 张: mean=0.615, p99=0.745, max=0.752
   缺陷 1200 张: mean=0.780, 强缺陷(方向突变等)接近 1.0

C++ DLconfig 中两个阈值建议改为:
   goodThreshold = 0.76    (Good / Warning 分界, 旧值 0.5409)
   ngThreshold   = 0.90    (Warning / NG 分界, 旧值 0.7231)

在 T=0.76 单阈值（两级, 良品误报率 0%）评估:
   良品误报率 0.0%
   缺陷总召回 55.8%
   强缺陷召回: direction_change 100% / blur_region 100% / local_shift 97%
             / spacing_jump 98% / arc_warp 93%
   弱缺陷(亮度斑/圆心大偏移/条纹宽异常)召回较低 ~0-26%: 模型能力边界, 非误检

注: C++ 若保持两级(Good/NG)可只用一个阈值 0.76; 若要三级(Good/Warning/NG)
    建议 good=0.76, ng=0.90。

--------------------------------------------------------------------------------
四、真实视频注意（域适配后仍有残余差距）
--------------------------------------------------------------------------------
对 11.avi / 13.avi 逐帧:
   旧模型(域适配前): 全部帧 score=1.0000（完全不认识真实视频 → 全 NG）
   新模型(域适配后): 11.avi score 0.908~0.957, 13.avi 0.955~0.986（有区分度了）
   - 域适配明显缩小了模拟/真实差距, 热力图开始有空间区分
   - 但真实视频帧分数仍普遍高于模拟良品, 若按 0.76 阈值判定仍会接近全 NG
   - 建议: C++ 集成后先用真实视频目视确认, 必要时再收集真实良品帧微调
